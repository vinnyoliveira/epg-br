Este site é só o guia eletrônico (EPG). Ele não transmite canais nem hospeda conteúdo.

Para assistir, use um provedor de TV ou streaming com assinatura. Aqui você copia o XMLTV e cola no player que já usa — TiviMate, IPTV Smarters, Kodi, Jellyfin, Sparkle — para carregar a grade.

Como usar em 3 passos

  1. Escolha o grupo

    Abra Completo ou Principais e escolha a versão: enriquecida, padrão, 24h ou leve.

  2. Copie o link

    Use o botão Copiar link do arquivo escolhido. Não é playlist, é só a grade.

  3. Cole no player

    No TiviMate, IPTV Smarters, Sparkle, Kodi ou Jellyfin, adicione como fonte XMLTV/EPG e atualize.

Arquivos

Perguntas frequentes

O que é EPG e XMLTV?

EPG é o guia de programação; XMLTV é o formato que os players leem. O EPG BR entrega só a grade, não os canais.

Preciso de uma lista de canais?

Sim. O EPG não transmite nada: ele apenas nomeia e descreve a programação dos canais que você já recebe do seu provedor.

Qual versão escolho?

Comece pelo Completo enriquecido. Se o aparelho travar, use o padrão, o 24h ou o leve. A lista Principais é menor.

Funciona no meu player?

Sim, em TiviMate, IPTV Smarters, Sparkle, Kodi, Jellyfin e outros que aceitem XMLTV. Adicione a URL como fonte de EPG e atualize.

Com que frequência atualiza?

A grade é refeita a cada 4 horas e o site mostra o horário da última geração, no horário de Brasília.

Por que um canal está sem grade?

A fonte não publicou a programação. Não inventamos horários para canais de evento; canais FAST podem receber grade estimada, sempre marcada.

O que significam ≈, ◐ e ↔?

≈ grade estimada, ◐ grade parcial, ↔ grade compartilhada com outro canal e ℹ aviso sem grade real.

Os logos estão incluídos?

O XMLTV aponta para banners 16:9 dos canais. Canais sem logo aparecem na lista de pendências no fim da página.

É gratuito? Tem anúncios?

Sim, é gratuito e sem anúncios ou cadastro. É um projeto aberto, mantido com GitHub Actions e GitHub Pages.

Como pedir um canal ou corrigir algo?

Use o botão Requisitar canal ou abra uma issue no GitHub. Nomes, aliases e logos podem ser corrigidos na curadoria.

Por que a classificação é 12, 14, 16 ou 18?

É o padrão brasileiro de classificação indicativa. O número e o rótulo aparecem na descrição para o player exibir a cor certa.

O que é a versão enriquecida?

Ela leva classificação, ano, duração, gênero, episódio e sinopse dentro da descrição, para players que não mostram as tags extras do XMLTV.
